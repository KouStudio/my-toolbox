# SORA TOOLBOX

自分専用のオフライン便利ツール集（PWA）。画像処理はすべて端末内で完結し、外部へ送信しません。

## 収録ツール
- ひみつマスク（個人情報マスキング）

## 追加ツール
単一HTMLファイルを「＋ HTMLを登録」から追加できます。登録したHTMLは端末内のIndexedDBに保存されます（このリポジトリには含まれません）。

## ホーム画面に追加
Android Chromeでこのページ（GitHub PagesのURL）を開き、メニュー「ホーム画面に追加」またはアプリ内の「ホーム画面にインストール」から追加してください。一度読み込めばオフラインでも使えます。
